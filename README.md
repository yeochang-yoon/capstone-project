# 상향 작업 보조 웨어러블 로봇

천장 타공이나 배관 작업처럼 팔을 들어 올린 채 수행하는 작업에서 어깨와 팔의 부담을 줄이기 위해, 어깨 굴곡을 보조하는 1자유도 구동형 웨어러블 로봇을 설계하고 제작했습니다. 착용자가 팔을 들어 올릴 때는 움직임을 허용하고, 작업 자세를 유지할 때는 팔이 아래로 처지는 것을 억제하도록 설계했습니다.

> 본 프로젝트는 대학교 캡스톤디자인 과정에서 진행한 프로젝트입니다. 현재 원본 소스코드는 보존되어 있지 않아, 프로젝트의 설계 및 구현 과정과 실험 결과를 정리한 논문을 중심으로 기록하였습니다.

**진행 기간** 2026년 2월~6월 · **팀 구성** 광운대학교 로봇학부 캡스톤디자인 9조, 4명

## 담당 역할

**CubeMars AK70-10 모터 구동과 Teensy 4.1–모터 드라이버 간 CAN 통신**을 담당했습니다.

- AK70-10의 MIT 모드로 목표 위치·속도, 비례·미분 게인, 피드포워드 토크를 전달하는 모터 제어 인터페이스를 구성했습니다.
- FlexCAN_T4를 사용해 1 Mbps CAN 통신을 구성했습니다. 제어값을 8바이트 명령 프레임으로 패킹하고, 모터 응답에서 위치·속도·토크 피드백을 복원했습니다.

## 사용 기술

| 영역 | 기술 및 장치 |
| --- | --- |
| 임베디드 제어 | Teensy 4.1, 상태 머신, 가상 임피던스 제어 |
| 모터 구동 및 통신 | CubeMars AK70-10, MIT 제어 프로토콜, CAN 1 Mbps, FlexCAN_T4 |
| 센서 | FSR 압력 센서, BNO085 9축 IMU |
| 기구 제작 | PLA 소재, FDM 3D 프린팅 |

## 시스템 구조와 핵심 구현

```mermaid
flowchart LR
    FSR["FSR · 커프 하중"] --> MCU["Teensy 4.1 · 상태 판단 및 제어"]
    IMU["BNO085 · 팔 링크 자세"] --> MCU
    MCU -->|"CAN · MIT 제어 명령"| Motor["AK70-10 · 어깨 굴곡 보조"]
    Motor -->|"CAN · 위치·속도·토크 피드백"| MCU
```

1. **기구 설계** — 어깨 굴곡 방향에 모터 한 개를 적용했습니다. 직렬 힌지 두 개로 어깨 외전 방향의 수동 움직임을 허용하고, 팔 길이에 맞게 커프 위치를 조절할 수 있도록 했습니다.
2. **센서 처리** — FSR의 ADC 값을 전압과 저항으로 환산해 커프 하중을 추정했습니다. BNO085에서 받은 쿼터니언은 오일러 각으로 변환해 팔 링크의 자세를 추정하는 데 사용했습니다.
3. **상태 전환과 단방향 가상벽** — 팔 링크의 각도 변화가 작아진 상태가 4초간 이어지면 현재 각도를 기준으로 지지를 시작합니다. 이후 하향 처짐에는 가상 강성과 피드포워드 토크로 대응하고, 팔을 더 들 때는 위쪽 움직임을 허용합니다. 커프 하중이 해제 임계값에 도달하면 자유 구동으로 복귀합니다.

## 실험 결과

- **기구 개선** — 초기 시제품 착용 중 백플레이트가 파손되고 팔 링크의 강성이 부족했습니다. 두 부품의 내부 채움 밀도를 20%에서 40%로 높인 뒤, 재시험에서 추가 파손 없이 기본 하중 지지 동작을 확인했습니다.
- **센서 보정** — FSR에 2 kg, 3 kg, 5 kg의 표준 하중을 각각 인가해 하중 변환과 상태 전환의 기준을 설정했습니다.
- **착용 시험** — 자세를 유지할 때 하향 처짐을 억제하고 팔을 더 들어 올릴 수 있음을 확인했습니다. 시험 중 상태가 바뀔 때 급격한 관절 진동이나 뚜렷한 동작 불연속은 관찰되지 않았습니다.

목표 보조 하중은 5 kg으로 설정했습니다. 팔이 수평일 때의 이론적 최대 정적 요구 토크는 9.8 N·m였고, 상향 자세 130° 이상에서 연속 지지에 필요한 최대 정적 토크는 약 7.5 N·m로 계산했습니다. 근피로 감소 효과와 장시간 구동 시 모터의 열적 성능은 후속 검증 과제로 남았습니다.
